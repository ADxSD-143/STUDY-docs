# Natural Language Processing (NLP)

**Goal:** AI/ML Engineer-level understanding + three resume-ready projects.  
**Learning style:** simple explanation → theory/formula → annotated code → real-world example → alternatives → diagrams → interview questions → practice.  
**Study pace:** target 60–90 minutes per module; split into short steps when needed.

## How to use these notes
- Start with the plain-language explanation, then follow the flowchart.
- Run examples and inspect outputs; do not just copy the code.
- Read what each important line does and why it exists.
- Use the alternatives table to choose an approach for a real requirement.
- Complete the checkpoint before treating a concept as learned.
- Resources are for deeper study; you do not need to consume every link before continuing.
