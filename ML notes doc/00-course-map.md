# Machine Learning Course Map
**Required flow: Maths → Python → Data → ML → Projects and Engineering.**

| Phase | Weeks | Focus | Guide |
|---|---:|---|---|
| Maths | 1–2 | Linear algebra, probability/statistics, derivatives and gradient descent | [Maths](phases/01-maths.md) |
| Python | 3 | Diagnostic refresh, NumPy/pandas and workflow | [Python](phases/02-python.md) |
| Data | 4–5 | Cleaning, EDA, visualization, features and leakage prevention | [Data](phases/03-data.md) |
| ML | 6–17 | Regression, classification, metrics, NB, KNN, trees, ensembles, validation, SVM, clustering, PCA and neural-network intro | [ML](phases/04-machine-learning.md) |
| Projects + Engineering | 18–24 | CampusFix, baselines, text classification, tests, API and release | [Projects](phases/05-projects-engineering.md) |
