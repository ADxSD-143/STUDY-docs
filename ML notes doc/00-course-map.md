# Machine Learning Course Map

**Required flow:** Python → Maths alongside practice → Data → Core ML → Mini-capstone.

| Phase | Weeks | Focus | Guide |
|---|---:|---|---|
| Python | 1 | Python fundamentals for a complete beginner | [Python](phases/02-python.md) |
| Maths | 1–2 alongside practice | Vectors, averages, probability, derivatives and gradient descent intuition | [Maths](phases/01-maths.md) |
| Data | 2–3 | NumPy, pandas, cleaning, EDA, train/test split and leakage | [Data](phases/03-data.md) |
| Core ML | 4–7 | Regression, classification, metrics, NB, KNN, trees, ensembles and validation | [ML](phases/04-machine-learning.md) |
| Capstone | 8 | CampusFix mini-project, baseline, evaluation and reproducible README | [Projects](phases/05-projects-engineering.md) |
