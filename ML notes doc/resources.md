## Mathematics: intuition first, derivation next

- [3Blue1Brown — Essence of Linear Algebra](https://www.3blue1brown.com/topics/linear-algebra): visual intuition for vectors, matrices, transformations, eigenvectors, and related ideas.
- [3Blue1Brown — Essence of Calculus](https://www.3blue1brown.com/topics/calculus): visual intuition for derivatives, integrals, and the chain rule.
- [MIT OpenCourseWare](https://ocw.mit.edu/): use for rigorous lecture notes, assignments, and deeper mathematical grounding. Select a course that matches the current topic rather than trying to complete all of MIT OCW.
- [Stanford Online](https://online.stanford.edu/): use for university-level course material; check prerequisites and whether the material is freely accessible.
- [Mathematics for Machine Learning (book website)](https://mml-book.github.io/): linear algebra, analytic geometry, matrix decompositions, calculus, probability, and optimization connected to ML.
- [Khan Academy](https://www.khanacademy.org/math): fill specific prerequisite gaps such as algebra, derivatives, probability, and statistics.

### Suggested order

1. Algebra and functions → vectors/matrices → dot product and norms.
2. Derivatives → partial derivatives → chain rule → gradients.
3. Probability → conditional probability and Bayes’ theorem → random variables and expectation.
4. Statistics → sampling, variance, estimation, confidence intervals, and hypothesis tests.
5. Optimization → loss functions, gradient descent, learning rate, and regularization.
6. Information theory when it becomes relevant: entropy, cross-entropy, and KL divergence.

For every math concept: explain it in your own words, work through one numeric example, implement a tiny NumPy experiment, and state which ML algorithm uses it.

## How to use a resource

For each lesson, record: resource and exact chapter/video; the question it helped answer; a short explanation in your own words; code you wrote independently; experiment/result; what still confuses you. Avoid copying a tutorial project line-by-line and calling it your own work.

## Maintenance rule

Links and course availability can change. Check the official course page, prerequisites, license/access conditions, and last-updated information before relying on a resource. Prefer official documentation for APIs and use videos mainly for explanation.
