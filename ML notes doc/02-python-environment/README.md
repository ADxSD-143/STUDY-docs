# Module 02 — Python and ML Environment

**Goal:** make your ML experiments easy to run, debug, and reproduce.

You already know Python fundamentals, NumPy, and pandas, so this module will avoid repeating those topics. We will focus on the practical workflow around ML code.

## Lessons

1. [Set Up a Reproducible ML Project](01-reproducible-ml-project.md)

## What you should be able to do

- Organise an ML project into clear files and folders.
- Use a virtual environment and install project dependencies.
- Record dependencies so the project can be recreated.
- Run code from a predictable project root.
- Recognise common environment and import errors.

## Learning rule

Follow the lesson on your own computer. Use the commands that match your current setup; do not install extra tools unless the lesson needs them.
