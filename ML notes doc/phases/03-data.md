# Data Preparation — Weeks 2–3

## Week 2 — NumPy and pandas essentials
Main resource: [CampusX Python playlist](https://youtube.com/playlist?list=PLxvLUL96MOO4saKDW4nHTCe1cDbDMTR5X), NumPy sessions 13–15 and pandas from session 16 onward. Supplements: [NumPy](https://youtu.be/VXU4LSAQDSc), [pandas](https://youtu.be/VXtjG_GzO7Q), [Matplotlib](https://youtu.be/c9vhHUGdav0).

Learn in order: NumPy arrays/shape/indexing/vectorized operations; pandas Series/DataFrame and CSV loading; filtering, missing values, duplicates, data types, groupby and simple merge; basic plots.

Deliverable: notebook loads a CSV, answers five questions, handles missing values and creates one useful plot.

## Week 3 — Cleaning, EDA and ML-ready data
Watch [CampusX data assessing/cleaning](https://www.youtube.com/live/-HnN8GBINnc?si=OvOHi67BLx1uJWe2) → [Krish Naik EDA and feature engineering](https://youtu.be/fHFOANOHwh8). Read [scikit-learn preprocessing](https://scikit-learn.org/stable/modules/compose.html) for train-only fitting.

Learn dataset rows/columns, target vs features, missingness, duplicates, numeric/categorical columns, outlier investigation, EDA plots, train/test split and leakage.

Deliverable: EDA report with data audit, 3 plots, documented cleaning decisions and a train/test split.
