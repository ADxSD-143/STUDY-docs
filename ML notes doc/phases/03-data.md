# Phase 3 — Data (Weeks 4–5)

## Week 4 — Cleaning and data quality
Watch in order:
1. [CampusX Data Assessing/Cleaning](https://www.youtube.com/live/-HnN8GBINnc?si=OvOHi67BLx1uJWe2)
2. [Krish Naik EDA and Feature Engineering](https://youtu.be/fHFOANOHwh8), focusing on missing values, duplicates, outliers and data types.
3. Read [scikit-learn preprocessing and composition](https://scikit-learn.org/stable/modules/compose.html) for train-only fitting.

Code: choose a real public dataset, audit shape/types/missingness/duplicates, document cleaning decisions, and split before fitting preprocessing. Do not remove outliers automatically without checking what they mean.

Deliverable: data audit table and cleaned data workflow.

## Week 5 — EDA, visualization and feature engineering
Watch in order:
1. [Sheryians AI School visualization](https://youtu.be/-jTD74eEy2I): relevant Matplotlib/Seaborn sections; Plotly is optional.
2. Continue [Krish Naik EDA/Feature Engineering](https://youtu.be/fHFOANOHwh8), focusing on encoding, feature engineering and leakage.
3. [Bro Code Matplotlib](https://youtu.be/c9vhHUGdav0) only if plotting needs revision.

Code: distributions, category counts, appropriate correlations, missingness analysis and 2–3 justified features. Explain why each feature would be available at prediction time.

Deliverable: EDA notebook with findings and leakage checklist. Gate: explain the target, row grain, split and excluded columns.
