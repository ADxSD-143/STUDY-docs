# Machine Learning Course Map

**Required flow:** Python → Maths alongside practice → Data → Core ML → End-to-end project workflow → Mini-capstone.

| Phase | Weeks | Focus | Guide |
|---|---:|---|---|
| Python | 1 | Python fundamentals for a complete beginner | [Python](phases/02-python.md) |
| Maths | 1–2 alongside practice | Vectors, averages, probability, derivatives and gradient descent intuition | [Maths](phases/01-maths.md) |
| Data | 2–3 | Data collection basics, NumPy, pandas, EDA, split and leakage-safe preprocessing | [Data](phases/03-data.md) |
| Core ML | 4–7 | Baselines, regression, classification, metrics, NB, KNN, trees, ensembles and validation | [ML](phases/04-machine-learning.md) |
| Project workflow | Throughout | Full lifecycle Stage 0–13 | [ML Project Workflow](../06-reference/ml-project-workflow.md) |
| Capstone | 8 | CampusFix: baseline, text model, evaluation, error analysis and reproducible README | [Projects](phases/05-projects-engineering.md) |
