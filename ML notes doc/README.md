# Machine Learning — Learn, Build, Evaluate

A beginner-first **8-week accelerated ML foundation**: Python → Maths alongside practice → Data → ML → Mini-capstone. It uses two fixed primary videos, assigned sections, coding deliverables and checkpoints.

**Time:** 8 weeks × 10 hours/week = 80 focused hours. This is a foundation sprint, not complete mastery or job readiness. Extend weeks when needed. Free-first; no paid APIs required.
