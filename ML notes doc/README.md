# Machine Learning — Learn, Build, Evaluate

A beginner-first **8-week accelerated ML foundation**: Python → Maths alongside practice → Data → End-to-end ML workflow → Mini-capstone.

**Time:** 8 weeks × 10 hours/week = 80 focused hours. This is a foundation sprint, not mastery or job readiness. Extend weeks when needed. Free-first; no paid APIs required.
