# Start Here — Docker Learning Path

The Docker notes are numbered so the folder follows a clear learning order.

1. Open the [full course index](README.md).
2. Begin with [01 — Installation and setup](01-installation.md).
3. Continue in numerical order. Documents 01–10 form the guided course and capstone.
4. Answer each lesson's checkpoint before moving to the next lesson.
5. Use [09 — Troubleshooting and lab log](09-troubleshooting.md) to record real errors and fixes.
6. Use documents 11–15 as reference sheets when needed.

**Current progress:** Part 1 and Part 2 have been introduced. Part 2's checkpoint still needs to be answered before starting the next lesson.

**Environment note:** Docker Desktop is installed with WSL 2, and the configured Docker disk image location is on the D: drive. Do not manually move Docker's WSL data or run destructive cleanup commands without checking what they delete.
